## Corresponding source

If you modify and run this program for users over a network, AGPL section 13 requires
prominently offering those users the Corresponding Source of your version at no charge.
A link to an upstream project, an older revision, or unpublished changes is not sufficient.
Redistribution also remains subject to the license, including its source requirements
when distributing object code.

The interface offers a source link based on the build's Git revision. Production deployments
must publish the actual corresponding source, including modifications and the scripts needed
to build and install it. See [deployment instructions](docs/how-to-deploy.md#source-availability)
for the source-link configuration. A link by itself does not publish missing source files.
